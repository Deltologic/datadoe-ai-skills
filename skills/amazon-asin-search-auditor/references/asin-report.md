# ASIN Visibility Report

Use `scripts/render-asin-report.js` for the final step. Build `report-data.json`, then render the fixed React template.

## Required files

- `RUN_DIR/per-asin-audit/ASIN/report-data.json` — complete report data object.
- `RUN_DIR/per-asin-audit/ASIN/report.html` — generated by `scripts/render-asin-report.js`.

## Render command

```bash
node amazon-asin-search-auditor/scripts/render-asin-report.js \
  --data RUN_DIR/per-asin-audit/ASIN/report-data.json \
  --out RUN_DIR/per-asin-audit/ASIN/report.html
```

## Data contract

`report-data.json` must contain:

```json
{
  "meta": {
    "asin": "B0XXXXXXXX",
    "marketplace": "XX",
    "sellerName": "Seller Name",
    "date": "YYYY-MM-DD",
    "asinUrl": "https://www.amazon.<tld>/dp/B0XXXXXXXX"
  },
  "listing": {
    "title": "Full product title",
    "imageUrl": "https://...",
    "price": 29.99,
    "currency": "<ISO 4217 code>",
    "rating": 4.3,
    "reviewCount": 1245
  },
  "summary": "Short paragraph summarising search performance and key findings.",
  "searchPerformance": {
    "impressions": 12000,
    "impressionsNote": "Monthly average",
    "clicks": 450,
    "clicksNote": "Monthly average",
    "conversionRate": 3.75,
    "organicRank": 12,
    "organicRankNote": "Best rank from the core data"
  },
  "areas": [
    {
      "name": "Title & Bullet Points",
      "rating": 3.5,
      "details": "2-3 sentence justification of the rating.",
      "recommendations": "2-3 sentence recommendations, or empty string if none needed."
    },
    {
      "name": "Images",
      "rating": 4.0,
      "details": "...",
      "recommendations": ""
    },
    {
      "name": "PPC Budget & Efficiency",
      "rating": 2.5,
      "details": "...",
      "recommendations": "..."
    },
    {
      "name": "Price & Ratings",
      "rating": 4.5,
      "details": "...",
      "recommendations": ""
    }
  ],
  "overallRating": 3.5,
  "priorityImprovements": [
    "First priority improvement (1-2 sentences).",
    "Second priority improvement.",
    "Third priority improvement."
  ],
  "competitors": [
    {
      "name": "Competitor product name",
      "price": "24.99 <currency>",
      "url": "https://www.amazon.<tld>/dp/...",
      "score": 4,
      "learnings": "2-3 sentences on what we can learn from this competitor."
    }
  ]
}
```

## Field notes

- `rating` — number from 0 to 5 in 0.5 steps. 5 = excellent, 3 = neutral, below 3 = poor.
- `overallRating` — same scale, derived from the areas table.
- `priorityImprovements` — up to 3 items; omit or leave empty array if no improvements needed.
- `competitors` — up to 5 items, sorted by `score` descending (most threatening first).
- `searchPerformance` — all fields optional; omit the whole object if no data is available.
- `listing.price` — numeric value (not formatted string). Use `listing.currency` for the currency code.
- `competitors[].score` — integer 0–5, where 5 = highest competitive threat.

## Rating bar colours

The template colours rating bars automatically:
- ≥ 4.0 → teal (good)
- ≥ 3.0 → amber (warn)
- < 3.0 → red (bad)
