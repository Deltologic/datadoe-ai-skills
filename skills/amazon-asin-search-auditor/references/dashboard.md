# Dashboard Report

Use `scripts/render-dashboard.js` for step 14. Do not redesign the report. Build `report-data.json`, then render the fixed React dashboard template.

## Required files

- `RUN_DIR/report-data.json` - the complete dashboard data object.
- `RUN_DIR/report.html` - generated by `scripts/render-dashboard.js`.
- `RUN_DIR/search_rasults/screenshots/st-SEARCH_TERM.png` - screenshots linked from Search mode.

## Render command

```bash
node amazon-asin-search-auditor/scripts/render-dashboard.js \
  --data RUN_DIR/report-data.json \
  --out RUN_DIR/report.html \
  --seller "SELLER DISPLAY NAME" \
  --marketplace "MARKETPLACE LABEL" \
  --run-folder RUN_DIR
```

## Data contract

`report-data.json` must contain:

```json
{
  "meta": {
    "sellerName": "Delto DE",
    "marketplace": "DE",
    "runFolder": "runs/run_YY_MM_DD_HH_mm"
  },
  "summary": {
    "searchTermCount": 0,
    "ownedAsinCount": 0,
    "totalCards": 0,
    "organicCards": 0,
    "sponsoredCards": 0,
    "termsWithOwnedHits": 0,
    "bestOrganicRank": 1,
    "bestPpcRank": 1
  },
  "coreSearchSummaries": [],
  "searches": [],
  "ownedAsins": []
}
```

Each `coreSearchSummaries[]` item must include `searchTerm`, `date`, `purchaseCount`, `impressions`, `clicks`, `organicRank`, `searchVolume`, and `searchImpressions`.

Each `searches[]` item is the marked search-result JSON from step 13 plus `screenshotLocation` or `screenshotLocation:`. Use a run-root-relative URL such as `search_rasults/screenshots/st-schuhdeo.png`; Search mode renders this as a `screenshot` button.

Each result inside `organicRanks[]` and `ppcRanks[]` should include `asin`, `asin_image_url`, `asin_url`, `price_value`, `price_currency`, `title` or `asin_name`, `rank` or `organicRank`/`ppcRank`, `mode`, and `isMyListing`.

Each `ownedAsins[]` item must include `asin`, `title`, `asin_image_url`, `bestOrganicRank`, `bestPpcRank`, and `appearances[]`. Each appearance should include `searchTerm`, `mode`, `rank`, `price_value`, `price_currency`, and `asin_url`.

## Dashboard behavior

- ASIN mode shows the owned ASIN list and ASIN detail panel.
- Search mode is full width and expands each term inline.
- Search mode marks owned ASINs, narrows the ASIN column, and includes an `ASIN mode` button for owned ASIN rows.
- Search mode includes a `screenshot` button on each term when `screenshotLocation` is present.
